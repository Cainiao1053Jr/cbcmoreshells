================================================================================
ShellExplosion 与 ScaledShellExplosion 爆炸威力对照
================================================================================
记号：
    S = 爆炸半径参数（size / explosive_power），两者含义完全相同
    k = ScaledShellExplosion 新增的抗性系数 resistanceFactor
    R = 方块的原版爆炸抗性 (Block.getExplosionResistance)
    u = 每条射线的随机强度因子，u ∈ [0.7, 1.3)，均值 1.0（原版写死，两者相同）

--------------------------------------------------------------------------------
一、代码层面唯一的差别
--------------------------------------------------------------------------------
ShellExplosion 给 CustomExplosion.Impl 构造器的 ExplosionDamageCalculator 传 null，
原版回退成 EntityBasedExplosionDamageCalculator；
ScaledShellExplosion 传入 ScaledResistanceExplosionDamageCalculator，它委托同一个
计算器，只把 getBlockExplosionResistance 的返回值乘上 k。

其余一切（射线数量、步长、随机因子、实体伤害、击退、掉落、粒子、音效、发包）
逐行一致。所以两者的差别可以用一句话完全描述，见第二节。

--------------------------------------------------------------------------------
二、精确等效关系（这是最本质、且严格成立的一条）
--------------------------------------------------------------------------------

    ScaledShellExplosion(S, k) 打在抗性为 R 的方块上
        ≡  ShellExplosion(S)  打在抗性为 k*R 的方块上

这是恒等式，不是近似：唯一被改动的量就是计算器返回的抗性值。
也就是说，k 不是"把爆炸变强/变弱"，而是"把全世界的方块抗性统一乘以 k"。

由此立刻得到两个推论：
  - 抗性 R = 0 的方块（TNT 等）：k 取任何值，结果完全一样。
  - 抗性越高的方块，受 k 的影响越大（见第四节表格右侧列）。

--------------------------------------------------------------------------------
三、能量消耗公式对照
--------------------------------------------------------------------------------
原版射线每前进 0.3 格扣一次能量，起始能量 f = S * u。

                              旧 ShellExplosion      新 ScaledShellExplosion
  每步固定损耗(距离项)          0.225                  0.225           （相同）
  每步抗性损耗                 (R + 0.3) * 0.3        (k*R + 0.3) * 0.3
  ------------------------------------------------------------------------
  每前进 1 格 · 空气            0.75                   0.75            （相同）
  每前进 1 格 · 抗性 R 的方块    1.05 + R               1.05 + k*R

  空中最大射程                  1.333 * S * u          1.333 * S * u   （完全相同）
  在抗性 R 材质中的穿深 D       S*u / (1.05 + R)       S*u / (1.05 + k*R)

关键：距离项 0.225 是常数，k 碰不到它 —— 这就是"范围不变"的来源，
      S 依旧是射程的硬上限，k 再小也冲不出 1.333*S*1.3 格。

--------------------------------------------------------------------------------
四、等效半径 S_eq —— "现在的 (S, k) 相当于原来的多大半径"
--------------------------------------------------------------------------------
令新旧穿深相等，S*u/(1.05 + k*R) = S_eq*u/(1.05 + R)，解得：

        S_eq(R) = S * (1.05 + R) / (1.05 + k*R)

注意 S_eq 依赖材质 R，不存在一个跟材质无关的单一等效半径。其取值范围：
        k > 1 时： S/k  <  S_eq  <  S     （方块越硬越接近 S/k）
        k < 1 时： S    <  S_eq  <  S/k
        R -> 很大时 S_eq -> S/k ；R -> 0 时 S_eq -> S

下表为 S_eq / S 的倍率（乘到原来的 S 上就是等效旧半径）：

  k \ R    0.5(泥土/沙)  3.0(木板)  6.0(石头/铁块)  9.0(末地石)  1200(黑曜石)
  ------------------------------------------------------------------------------
  0.25       1.319        2.250       2.765          3.045        3.990
  0.50       1.192        1.588       1.741          1.811        1.998
  0.75       1.088        1.227       1.270          1.288        1.333
  1.00       1.000        1.000       1.000          1.000        1.000   <- 原版
  1.50       0.861        0.730       0.701          0.691        0.667
  2.00       0.756        0.574       0.540          0.528        0.500
  3.00       0.608        0.403       0.370          0.358        0.333
  4.00       0.508        0.310       0.281          0.271        0.250
  8.00       0.307        0.162       0.144          0.138        0.125

读法举例：k = 2 时，对石头而言这发弹相当于把原来的半径打了 0.540 折；
          但对泥土只打到 0.756 折 —— k 对软材质的削弱更温和，对硬材质更狠。
          这正是"抗性系数"和"直接调小 S"最大的行为差异。

（方块抗性为原版参考值，mod 方块请以游戏内实际数值为准。）

--------------------------------------------------------------------------------
五、实际穿深对照（以 hesh_shell 为例，S = 8.5，取平均 u = 1.0）
--------------------------------------------------------------------------------
公式 D = 8.5 / (1.05 + k*R)，单位：格

  k      泥土 R=0.5    木板 R=3.0    石头 R=6.0    末地石 R=9.0
  ---------------------------------------------------------------
  0.5      6.54          3.33          2.10          1.53
  1.0      5.48          2.10          1.21          0.85     <- 原版 ShellExplosion
  2.0      4.15          1.21          0.65          0.45
  4.0      2.79          0.65          0.34          0.23

空中射程（无遮挡）三档完全一样：平均 11.3 格，随机区间 7.9 ~ 14.7 格。

--------------------------------------------------------------------------------
六、破坏体积对照
--------------------------------------------------------------------------------
均质材质中弹坑近似为球形，体积 ∝ 穿深的三次方，于是

        新体积 / 旧体积 = [ (1.05 + R) / (1.05 + k*R) ]^3

  k      泥土 R=0.5    木板 R=3.0    石头 R=6.0    黑曜石 R=1200
  ----------------------------------------------------------------
  0.5      1.69x         4.00x         5.28x         7.98x
  1.0      1.00x         1.00x         1.00x         1.00x
  2.0      0.43x         0.19x         0.16x         0.125x
  4.0      0.13x         0.030x        0.022x        0.016x

所以 k 的手感是非线性的：k 从 1 调到 2，对石头的挖掘量直接掉到约 1/6。
建议实战微调幅度控制在 0.8 ~ 2.0 之间，超过 3 基本等于"打不动硬方块"。

--------------------------------------------------------------------------------
七、不受 k 影响、两者完全一致的部分
--------------------------------------------------------------------------------
  项目                      旧 ShellExplosion      新 ScaledShellExplosion
  --------------------------------------------------------------------------
  射线条数 / 步长            1352 条 / 0.3 格        相同
  空中射程                  1.333 * S * u           相同
  实体伤害作用半径           2 * S                   相同
  贴脸最大伤害               14 * S + 1              相同
  实体击退                  按 2*S 衰减              相同
  方块掉落率                 1 / S                   相同
  editBlock 表面变换         同                      相同（逻辑逐行照搬）
  粒子 / 音效 / 烟柱判定      同                      相同（按 S 缩放）
  客户端表现                 ExplosionType.SHELL     相同（同 S 下发）

这一栏是新方案相对"直接改小 S"的核心优势：调 k 只动对方块的穿透力，
不会连带把实体伤害、击退、掉落率、爆炸视觉一起改掉。
如果改的是 S，上表里每一行都会跟着变。

--------------------------------------------------------------------------------
八、反解：想要某个等效威力，k 该取多少
--------------------------------------------------------------------------------
已知希望在材质 R 上等效于旧的半径 S_eq（当前 size 仍为 S）：

        k = [ (1.05 + R) * S / S_eq - 1.05 ] / R

算例：hesh_shell 当前 S = 8.5，希望它对石头(R=6)的破坏力只相当于旧的 S_eq = 4.25
      （即对方块威力减半、但爆炸范围和对实体伤害保持 8.5 不变）：
        k = (7.05 * 8.5/4.25 - 1.05) / 6 = (14.10 - 1.05) / 6 = 2.175
      验算：新 D = 8.5/(1.05+2.175*6) = 8.5/14.10 = 0.603 格
            旧 D = 4.25/(1.05+6)      = 4.25/7.05  = 0.603 格   ✓

--------------------------------------------------------------------------------
九、这些公式的适用范围
--------------------------------------------------------------------------------
1. 第二节的等效关系是精确的；第三节之后的穿深/体积公式是连续化近似，
   忽略了 0.3 格步长的量化和 "f > 0 才计入 toBlow" 的边界判定，
   在 D 只有零点几格时相对误差会明显放大（实际弹坑本来也是参差不齐的）。
2. u 是逐射线随机的，同一发弹不同方向的穿深会在 0.7 ~ 1.3 倍之间波动，
   表中数值都是均值。
3. 混合材质（例如石头夹钢板）要沿射线逐段累加每格开销 (1.05 + k*R_i)，
   直到累计超过 S*u 为止，不能直接套单一材质的公式。
4. k 会夹到 >= 0；k = 0 表示完全无视方块抗性，此时穿深退化为纯射程
   1.333*S*u（基岩等 shouldBlockExplode 拒绝的方块仍然打不掉）。
