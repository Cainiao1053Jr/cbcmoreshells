# 变更记录

## 2026-08-02 为 SLATE_STEEL_BLOCK 添加连接纹理（参考 Create 的 BRASS_CASING）

### 新增/修改的代码
1. src/main/java/com/cainiao1053/cbcmoreshells/index/CBCMSSpriteShifts.java
   - 新增 import：com.simibubi.create.foundation.block.connected.CTSpriteShifter
   - 新增常量 SLATE_STEEL_BLOCK = omnidirectional("slate_steel/slate_steel_block")
   - 新增私有工具方法 omnidirectional(String)，使用 Create 的
     CTSpriteShifter.getCT(AllCTTypes.OMNIDIRECTIONAL, 本体贴图, 连接贴图)，
     与 Create 的 BRASS_CASING 采用同一 CT 类型（8x8 = 128x128 连接图集）。
     本体贴图：cbcmoreshells:block/slate_steel/slate_steel_block
     连接贴图：cbcmoreshells:block/slate_steel/slate_steel_block_connected

2. src/main/java/com/cainiao1053/cbcmoreshells/CBCMSBlocks.java
   - 新增 import：com.simibubi.create.content.decoration.encasing.EncasedCTBehaviour
   - SLATE_STEEL_BLOCK 注册链上新增两个 onRegister（与 Create casing 的做法一致）：
     .onRegister(CreateRegistrate.connectedTextures(() -> new EncasedCTBehaviour(CBCMSSpriteShifts.SLATE_STEEL_BLOCK)))
     .onRegister(CreateRegistrate.casingConnectivity((block, cc) -> cc.makeCasing(block, CBCMSSpriteShifts.SLATE_STEEL_BLOCK)))
     EncasedCTBehaviour 依赖 CreateClient.CASING_CONNECTIVITY 判断两侧方块能否连接，
     因此 casingConnectivity 注册是必需的，缺少它连接纹理不会生效。

### 资源重命名
6. assets/cbcmoreshells/textures/block/slate_steel/slatesteel_block.png
   -> assets/cbcmoreshells/textures/block/slate_steel/slate_steel_block.png
   原文件名缺少下划线，与需求中的本体材质路径
   cbcmoreshells:textures/block/slate_steel/slate_steel_block 不一致，故重命名。
   （该文件此前未被任何 json/java 引用，重命名无副作用。）

### 备注
- 连接贴图 slate_steel_block_connected.png 已存在且为 128x128，与 Create 的
  brass_casing_connected.png 规格一致，无需改动。
- 连接贴图无需写入 atlases，Create 的 SpriteShifter 会自动把目标贴图拼入方块图集。
- 校验方式：因本机 gradle 无法离线解析 deobf 依赖，改用 javac 以本地缓存 jar 作为
  classpath 编译整个 src/main/java；上述两个 java 文件均无报错
  （唯一报错来自无关文件 api/vs/PhysShipWrapper.java，系临时 classpath 中
   Valkyrien Skies API 版本不一致导致，与本次改动无关）。
